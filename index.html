Audio Thread Isolator (ATI)

Lightweight Windows utility to isolate audio threads to a dedicated CPU core and manage process & thread priorities.

Key Features / 主な特徴

  • Automatic Audio Thread Identification & CPU Core Isolation: Detects real-time audio delivery threads across WASAPI, ASIO, audiodg.exe, Chromium Audio Service, DAWs, Roon (RoonAppliance.exe / RAATServer.exe), and Voicemeeter (VBAN & VAIO/AUX DSP) and pins them to a dedicated CPU core while evacuating non-audio threads.
  • 3D Priority Matrix Picker & Fixed KPRIORITY (1–31): Interactive 6×7 Priority Matrix Picker plus direct kernel priority control (Fixed 1–31 via NtSetInformationThread).
  • Automatic HighQoS (EcoQoS / Power Throttling OFF) & Hybrid Dynamic Priority Boost Suppression: Eliminates OS frequency throttling, timer coalescing, and dynamic priority wake-up jitter on isolated audio cores with zero steady-state API overhead.
